# 🖥️ micro-twitter-web
Interface web moderna e responsiva para o projeto micro-twitter-api, simulando uma rede social inspirada no Twitter com funcionalidades básicas de timeline, postagens, login e interação entre usuários.

🎯 Funcionalidades

- Autenticação de usuários (login/cadastro)

- Publicar e visualizar tweets

- Curtir, retweetar e deletar postagens

- Timeline personalizada com feed em tempo real (ou quase!)

- Navegação intuitiva e design inspirado em redes sociais reais

🧰 Tecnologias

- React.js com Hooks modernos

- Axios para comunicação com a API

- React Router DOM para controle de rotas

- Estilização com CSS Modules, TailwindCSS ou styled-components (dependendo do projeto)

- Integração total com a <a href="https://github.com/portfolio-lucas/micro-twitter-api" target="_blank">micro-twitter-api</a>

💡 Casos de uso

- Aprendizado de integração front-end com APIs REST

- Prototipagem rápida de redes sociais

- Prática de autenticação e controle de sessão no React

- Possível base para testes com backend em Node, PostgreSQL, Supabase, etc.
